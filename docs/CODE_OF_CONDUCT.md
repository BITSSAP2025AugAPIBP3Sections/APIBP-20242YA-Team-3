# Code of Conduct

## Our Pledge

To foster an open and welcoming environment, we pledge to make participation in this project safe and respectful for everyone. We value constructive collaboration and expect contributors to behave professionally and courteously.

## Who This Applies To

This code of conduct applies to all contributors, maintainers, reviewers, and participants in project-related spaces including the repository, issue trackers, pull requests, and any official project channels.

## Expected Behavior

- Be respectful and considerate in all communications.
- Assume good faith: people contribute for many reasons and may have different backgrounds and levels of experience.
- Provide constructive, actionable feedback when reviewing code or issues.
- Help others when you can and ask for help when you need it.
- Use inclusive language and avoid slang or terms that could be exclusionary.

## Unacceptable Behavior

Examples of unacceptable behavior include, but are not limited to:

- Harassment, intimidation, or discrimination of any kind.
- Abusive, vulgar, or offensive language.
- Personal attacks or targeted insults.
- Publishing private or identifying information about others (doxing).
- Sustained derailing of conversations or malicious disruption of project activities.

## Reporting and Enforcement

If you experience or witness behavior that violates this Code of Conduct, please report it to the project maintainers. Provide as much context as possible (links, screenshots, timestamps, usernames) so we can fairly evaluate the situation.

Reports can be sent to the project email: "gupta.shrishti.0111@gmail.com" or opened as a private GitHub issue marked for maintainers only.

When a report is received, maintainers will:

1. Acknowledge receipt of the report in a timely manner.
2. Investigate the issue confidentially and gather relevant information.
3. Apply appropriate, proportional actions if the report is validated. Actions may include a private warning, temporary removal of commit/PR privileges, suspension from project channels, or removal from the project.

All parties involved will be treated fairly and given the opportunity to respond.

## Scope and Exceptions

This Code of Conduct is intended to cover behavior in project spaces and events. It is not intended to constrain private conversations or communications outside of project spaces unless they directly affect the project or its members.
